# Roadmap

These are ideas. **None of them is built unless a line says so.** Nothing here is a promise or a date, and none of it is a measured result. Links point to public projects where we saw a similar idea. We write our own code, and we copy no text, code or data from them.

## Ideas we want to build

- **Hand-off record.** When a Task ends or is lost, write a short state record that any agent can continue from. Test it against redoing the steps. Seen in [stint](https://github.com/QuintinBotes/stint).
- **A free "check first" call.** Ask what already exists, and run nothing. Seen in [agentboard](https://github.com/jai-rathore/agentboard).
- **Named intake outcomes.** Each new shared object gets one result: duplicate, better, new, conflict, or injection attempt. Seen in [web-agentic-memory](https://github.com/heycodingkr/web-agentic-memory).
- **Listed only after it ran.** A feed item earns its status from a separate sandbox install test. Importing still runs nothing. Seen in [pickfit](https://github.com/ncchen99/pickfit).
- **Cache layout and a stable prefix.** The cheapest test on our token rise, measured with a paired test. Seen in [agent-cost-harness](https://github.com/IrwinJam/agent-cost-harness).
- **Savings count only when the same tests pass.** Fewer tokens mean nothing if the job fails more often. Seen in.
- **Shadow stage for new deciders.** Set the threshold from early labeled calls before a decider takes live work. Seen in [decideonce](https://github.com/jcsancho/decideonce), [SwitchBoard](https://github.com/KanishkNoir/SwitchBoard).
- **A forgetting check in the fine-tune gate.** A new model must keep what the old one could do.
- **Warn at the moment of the mistake.** Shim rules that speak up when an agent is about to make a known error. Seen in [ai-symbiont](https://github.com/smalls257/ai-symbiont).
- **Claims checked against the log.** A checker compares what a report says with what the run recorded, and looks again later. Seen in [metacog](https://github.com/song2h/metacog).
- **Tool lists that stay small as they grow.** Fabric's tool list stays short as Tasks and Task Objects grow.
- **Rules from real failures.** For example: something unread is never reported as absent. Seen in [callreader](https://github.com/kimdooo-a/callreader).
- **Agent Skills export.** Export NGO kits as skill folders that outside installers can find. Nothing runs at install, and nothing is granted.
- **Lock file for kits and packs.** Pin exactly what a kit was built from.
- **Repo-following catalog.** Fabric Intelligence follows repositories, using the GitHub API.
- **Model tiers.** Named tiers across the shim, OmniNodes, workers and fine-tune swaps.
- **Tool-output reduction.** Would be our own build, to test with a paired run.
- **Hidden-text scan at intake.** Scan outside content for hidden instructions before it becomes a Task Object.
- **Generated README counts.** Counts in READMEs come from records, and a scratch-copy check runs them.
- **A `doctor` for agents.** A call that tells an agent what is wrong with its setup.
- **Declarative held-out tests.** Fine-tune gates and benchmarks read their tests from a plain file.

## Ideas we are still learning about

- Traces grown into reusable skills
- Named checks with scores for checker agents
- A failure reason sent back to the maker in a loop
- Task state re-injected each turn
- Per-context sensitivity tracking, beyond refusal by model name
- Replay and versioned graphs for durable work
