# Assembler

Reads how a Task looks, finds similar earlier Tasks, and picks a harness, model, tools, Task Objects, rules and a budget for that one Task. It starts when we start it. See `docs/how-it-learns.md`.

Tests need the Fabric source: `FABRIC_SRC=/path/to/fabric/src python3 -m pytest -q tests`. Live runs need your own settings. Records stay out of git.
