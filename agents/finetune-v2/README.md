# Fine-tune v2: records and tools

A second fine-tune of Muse Glimmer 30B for choosing a Task Object or saying none. These are the plans registered before scoring, the results and the model record. Weights stay private. See NOTICE-META-MODELS.txt.

"Another model" in these copies is the second blind reader. Its name is generalized here, so these files differ from the private originals by those words only. Real Task text, reader answers and the training data stay private, so these files can't re-run the panel on their own.

The tools show how the run was made. They name our working folders and need your own settings, and the panel readers' tools aren't included.
