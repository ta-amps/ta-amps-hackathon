# Film engine

The isometric motion graphics behind the Teleion Fabric films: `film.js` draws every scene on a canvas from `data.js`, and `tools/` renders and checks it. No footage, voice, music, fonts or finished films are stored here.

Most tools read `TELEION_NOTES` for local takes and voices, so they need your own media to render a full film. To see the scenes, serve this folder and open `index.html`.
