# Contributing

Corrections make this kit useful. Every correction needs a **source link** and the **date you checked it**.

## Reporting a correction

Open an issue with the **Correction** template. Tell us:

- the page and the line that's wrong;
- what the source says, in your own words, with a short quote if wording matters;
- the source URL and the date you checked it.

## Changing a page yourself

1. Branch from `main` (`docs/<slug>`).
2. Edit the page. Keep the disclaimer line at the top, and keep the as-of date current for anything you re-checked.
3. Summarize in your own words. Don't paste rules, emails or docs in full.
4. Run `make check`.
5. Open a pull request that lists each changed fact with its source and date.

## Observations

Opinions are welcome in `observations/`, one file per day or topic, using
[templates/observation-entry.md](templates/observation-entry.md). Label them as opinion and date them.

## What we won't merge

- Copies of the Official Rules, the event page, emails, recordings or transcripts.
- Keys, tokens, personal data, or names of private products and accounts.
- Facts without a source.
