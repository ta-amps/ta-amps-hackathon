# Meta Global AI Developer Hackathon at a glance

| | |
|---|---|
| Hosts | Meta and Cerebral Valley |
| Format | Virtual, worldwide, free for accepted applicants (cap of 20,000) |
| Runs | Oct 26, 12:00 PM ET (16:00 UTC) to Nov 4, 9:00 PM ET |
| Submission deadline | **Nov 4, 9:00 PM ET = 2026-11-05 02:00 UTC** |
| Tracks | Indie developer (individuals, students, teams up to 4) and Startup (founders building a product) |
| Themes | Build for Your World; Push the Frontier |
| Prize pool | $1,000,000: Indie $400,000, Startup $550,000, bonus awards up to $50,000 |
| Judging | Impact 30%, Use of Meta AI Tooling 25%, Demo 25%, Technical Depth & Execution 20% |
| Judging window | Nov 4 to Nov 8; live finals and winners on Nov 9 |
| Credits | $150 Meta Model API credit per accepted participant (claim by Nov 4, 9:00 PM ET); partner credits for select participants |
| Submit at | [cerebralvalley.ai/…/hackathon/submit](https://cerebralvalley.ai/e/meta-ai-developer-hackathon/hackathon/submit) |
| Updates | [Discord](https://cerebralvalley.ai/e/meta-ai-developer-hackathon/discord), email blasts, the [event page](https://cerebralvalley.ai/e/meta-ai-developer-hackathon) |
