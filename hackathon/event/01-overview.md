# Overview

A ten-day, virtual, worldwide hackathon run by Meta and Cerebral Valley. Accepted applicants build with Meta's newest
models and compete for a $1,000,000 cash prize pool across two tracks.

## What you get

- Access to Meta's models through the **Meta Model API**. The event page names the Muse Spark series, Muse Wonder,
  Muse Image and SAM 3.1.
- Meta's **open-weights models**, which you can run without a Model API account.
- **Muse Code**, Meta's coding agent.
- **Live workshops** from Meta and partners from Oct 27 to Nov 4, plus **office hours on Discord**.
- **$150 in Model API credits** per accepted participant (claim required; see [10-credits.md](10-credits.md)).
- **Partner credits** for select participants from Baseten, Modal and Fireworks.
