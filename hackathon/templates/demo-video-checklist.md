# Demo video checklist

Demo is 25% of the score, and it includes "the quality of the demo video" and whether the product "holds up live".
No length is published (as of Oct 26); about three minutes plus a 60-second cut is a sensible target.

## Before recording

- [ ] Script written: the hook in the first 20 seconds, then the strongest moment, then the proof, then the limits
- [ ] Every number on screen comes from a committed results file
- [ ] Anything synthetic is labelled on screen
- [ ] Demo mode works with the network off (snapshot), at 1920x1080, with body text at 16 px or larger
- [ ] Tools pinned for the recording: no auto-updates (for Muse Code, `MUSE_NO_AUTO_UPDATE=1`), notifications off
- [ ] A fallback recording made a day early

## Recording

- [ ] Real screen capture; label any generated visual as such
- [ ] Your own voice; captions on
- [ ] No keys, tokens, emails or personal tabs visible anywhere on screen
- [ ] No dead air: each step starts within a second of the last

## After

- [ ] Watched end to end in a private browser window, with sound and with captions only
- [ ] 60-second cut, with no jargon in the first 20 seconds
- [ ] Uploaded, link tested signed out, and pasted into the submission
- [ ] Description and video say the same thing about results and limits
