# Observations and comments

Personal notes from building during the hackathon: gotchas, inconsistencies, things that surprised us, and opinions.
**Everything in this folder is opinion or first-hand observation, dated and signed. It is not official and not a rule.**

## How to add one

- One file per day or per topic, named `YYYY-MM-DD-topic.md`, using
  [../templates/observation-entry.md](../templates/observation-entry.md).
- Separate what you saw (with a link and date) from what you think it means.
- When an observation turns into a confirmed fact, move the fact into [../event/](../event/README.md) or
  [../meta-platform/](../meta-platform/README.md) with its source, and leave a pointer here.
- Be fair to the organizers and vendors: a doc mismatch is a note, not an accusation.
