# Day one: inconsistencies and gotchas

**Opinion and first-hand observation, Oct 26, 2026.** Each item says what we saw, where, and what we'd do about it.

## The event

| # | What we saw | What we'd do |
|---|---|---|
| 1 | The waiver page carries Official Rules dated Oct 25, yet the event pages still say the rules "will be published before the Hackathon begins" | Treat the waiver as the rules, and re-check it for a newer version before submitting |
| 2 | The sources list different models: the event page has Muse Spark, Muse Wonder, Muse Image and SAM 3.1; Meta's copy leaves out Wonder; the rules say Muse Spark, Glimmer and SAM 3 | Build with what the event page lists; the rules pull it in ("any other Meta AI products identified on the Event page") |
| 3 | The credit is "valid for a 10-day development window" in the rules but does "not expire" in the Credit Terms | Spend as if it lasts ten days |
| 4 | No video length is published | Aim for about three minutes, plus a 60-second cut |
| 5 | Problem statements and the schedule are behind the participant sign-in | Read them early, since Impact (30%) includes fit with a problem statement |
| 6 | Changing the repository after the deadline marks the project late | Freeze the repo at the deadline; keep working on another branch |
| 7 | The kickoff stream is a Vimeo live event, and the rules make recordings the organizers' property | Summaries only; ask on Discord about a replay |

## Meta's platform

| # | What we saw | What we'd do |
|---|---|---|
| 8 | Muse Code subscriptions default to Contributor mode, which lets Meta train on your content; the Terms (s.3.3) treat coding-harness subscriptions as Contributor by default | Pass `--contributor-mode off` or set `MUSE_CONTRIBUTOR_MODE=0` on every run that touches anything sensitive |
| 9 | Muse Code's default model is `muse-spark-1.2`, while the Model API docs recommend `muse-spark-1.3` | Set the model explicitly where you can |
| 10 | The docs pipe the installer to `sh`, but the script uses bash-only syntax | Download it, read it, run it with bash ([../scripts/install-muse-code.sh](../scripts/install-muse-code.sh)) |
| 11 | The model docs write `sam-3.1`; the product page writes `sam-3-1` | Confirm with `GET /v1/models` |
| 12 | Prompt Guard 2 is open weights only, gated on Hugging Face with manual approval | Request access on day one |
| 13 | LlamaFirewall's AlignmentCheck needs a non-Meta provider key | If you want Meta-only model calls, write your own trace review on Muse models |
| 14 | `npx @astryxdesign/cli init` writes AGENTS.md and CLAUDE.md, and `npx astryx` (unscoped) is an unrelated package | Don't run `init` in a repo that already has agent files; always use the scoped name |
| 15 | Muse Code's `.muse/hooks.json` format isn't documented, and hooks run outside the sandbox | Add hooks only once the format is documented, and only hooks you wrote |
| 16 | Voice Transcribe accepts at most 10 minutes of audio and 32 MB per request | Chunk long audio ([../tools/transcribe/](../tools/transcribe/README.md)) |
